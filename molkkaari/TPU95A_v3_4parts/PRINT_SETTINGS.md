# 推奨印刷設定 — モルッカーリ本体 v3.0（TPU 95A／4パーツ）

> **試作・実機の接合強度は未検証。** 240mmの本体4本を先に印刷せず、必ず接続試験片2本から確認してください。

## 対応範囲
- プリンター：**Flashforge Adventurer 5M**（造形範囲220×220×220mm）。
- 材料：TPU 95A。**このv3.0のSTLは0.4mmノズルを前提に作成**されています。0.8mmノズルへ切り替えた場合は、スライスプレビューで細かいスナップ、鍵穴の入口、前面「Mölkky」の凹文字が消えたり塞がったりしないか確認してください。**0.8mmでの印刷品質・嵌合は未検証。** 問題があれば0.8mmに合わせたCAD修正が必要です。
- フィラメントプロファイル：Orca-Flashforgeの `Generic TPU` をベースに、別名でユーザープリセットを保存。

## 暫定的な初期設定（0.4mmノズル）
| 設定 | 初期値 |
|---|---|
| ノズル温度 | **フィラメントメーカー指定範囲を優先**。例えば230℃がその範囲内なら開始候補 |
| ベッド温度 | 45〜55℃程度（ビルドプレートの指定を優先） |
| レイヤー高さ | 0.20mm |
| 初層速度 | 15mm/s |
| 外壁 / 内壁 | 20 / 20mm/s |
| インフィル / トップ面 | 20 / 20mm/s |
| 最大体積速度 | 1.5mm³/sから開始 |
| リトラクション | **0mmから原因切り分け**、糸引きが強い場合のみ少量を再検討 |
| サポート | 原則OFF。スライスプレビューで例外を判断 |
| ブリム | 大きな長尺部材では4〜6mmを必要に応じて |
| 造形倍率 | 100% |

※上記は詰まりやすいTPU 95Aを低速で試すための暫定値であり、実機の安定印刷保証ではありません。初層、冷却、材料温度は銘柄で変わります。

## 0.8mmノズルを使う場合の注意
- プリンター本体とOrca-Flashforgeの**両方で実際の0.8mmノズル径を選び、必ず再スライス**。
- 0.8mmライン幅の目安0.85〜0.95mm、レイヤー高さ0.24〜0.32mm程度。ただし**v3.0本体をこの条件でそのまま印刷することは推奨しません**。試験片のピン・鍵穴・文字形状をスライスと実印刷でチェックし、必要なら設計し直すこと。
- 0.8mmへ変更してもエクストルーダーの送り不良、湿気、リール抵抗が原因の「途中で吐出停止」は直らない場合があります。

## 造形方向と順番
1. `02_TEST_FIRST/TEST_180DEG_MALE_END.stl` と `TEST_180DEG_FEMALE_START.stl` を先に印刷し、嵌合と保持を確認。
2. 左右45°のオス・メス試験片も確認。
3. 問題なければ `01_BODY_4_STL` 内4本を**各1個**印刷。
4. 付属STLは斜め配置済み。**広い天面をプレートに接地し、地面側の収納空洞を上向き**にして印刷。端を上向きに直立させない。
5. スライス後、鍵穴・凸部・「Mölkky」の文字とレイヤーごとの経路を確認する。

## 合否
- 中央と45°のジョイントが軽い手作業で入ること、上下や左右の負荷で簡単に外れないこと。
- 前面文字が判読できること。
- 置いたときに角度を保持でき、空洞が潰れないこと。
- 未検証のまま木のモルック棒による耐衝撃性を保証しないこと。

## TPUの詰まりに関する注意
途中で吐出が止まったら印刷を停止。リトラクション・最大体積速度・チューブの急な曲がり・リールの抵抗・送りギア・フィラメント乾燥・ノズルの残留樹脂を確認し、**小さな試験片で安定吐出を確かめてから**大型の本体を印刷してください。
