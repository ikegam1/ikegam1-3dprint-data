## 印刷前の確認

1. 各フォルダの `README_*.md` を読む。
2. 造形方向・サポート有無をOrca-Flashforgeで確認する。
3. 本体の長いパーツを印刷する前に短い嵌合テストを印刷する。
4. 測定具はジョイントの連結・回転・収納および3,500mmの実寸を確認してから本番に進む。

## 注意事項

- `body_v2.3` は設計上の全長約1000mm、4枚×240mmと約40mmの連結間隔を含むモデルです。
- `measure_3500mm_v11.1_PROTOTYPE` は未完成の実験版です。完全な収納性能・耐久性・長さ精度は保証されません。
- 以前の試作でPETG製の回転ジョイントが組み立て時やサポート除去時に折れました。慎重にテストしてください。
- データは利用者とChatGPTの反復試作によるもので、工業製品として検証済みではありません。
