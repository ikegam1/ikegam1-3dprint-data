# モルッカーリ3.5m測定具 v11.1 — PETG回転ジョイント改良版

対象: Flashforge Adventurer 5M（220×220×220mm）、PETG、ノズル0.4mm想定。
**STL作成・CAD形状検査済みですが、実機での連結・引張保持力・耐久性は未検証です。**

## v11から変更した部分
- すぐに折れていた細い球頭突起を廃止し、直径2.70mmの頭のない短い円柱軸へ変更。
- 受け側は内径3.30mmの回転穴と、上側へ抜ける斜めの導入溝を一体化。球を押し込んで受けアームを無理に広げる必要がない構造。
- 突起根元を太くし、補強斜面と一体化。軸の一端を造形プレートに近い高さとし、先端のサポート除去を不要にする向き。
- 回転軸の高さ・受けアームの厚みを増やして、穴周囲の最薄肉厚を約1.25mmに確保。
- 折りたたみ時の肉同士の干渉を再チェックし、0〜180°の9角度で干渉がないことをCADで確認。
- **v11に含めたヒンジ試験STLは、上折り凸部と下折り受け部が混在していた誤りを修正。** 今回はTOP用とBOTTOM用を別々に同じ向きで組み合わせています。

### 組み立ての考え方
軸（凸側）を受け側の斜め導入溝から滑らせて丸穴の中心まで下ろします。2つの耳に同時に入れます。**力任せに押し込んだり、両耳を広げたりしないでください。** 通常の伸ばした状態では、引っ張る力が溝の出口と逆方向に作用する設計です。ただし、折り曲げ中に外れないかは実機確認が必要です。

## 最初に印刷するもの（必須）
`02_FIRST_TEST_STL/TEST1_NEW_SLIDE_HINGE_TWO_PIECES_EDGE_DOWN.stl`

これで上折り用の短い板が2本できます。

上折り用が連結・折りたたみ・引張を問題なく試せたら、
`02_FIRST_TEST_STL/TEST1B_BOTTOM_SLIDE_HINGE_TWO_PIECES_EDGE_DOWN.stl`
を印刷し、下折り用も確認してください。

確認項目:
1. サポートを剥がさずに軸先端まで正常に印刷できる。
2. 斜め溝から、力をかけずに軸が穴へ移動できる。
3. 伸ばした状態で軽く引いても外れず、180°までゆっくり折りたためる。
4. 折りたたみ途中で勝手に溝から軸が抜けない。白化・割れがない。

**1つでも失敗すれば本番21本はまだ印刷しないでください。**

## 印刷条件の目安
- 素材 PETG、積層0.20mm、ノズル温度240℃前後、ベッド80℃前後（フィラメントの推奨値を優先）
- 外壁30〜40mm/s、初層15〜20mm/s、ブリム4〜6mm
- STLは長い板の**細い縁を下**にする向きへ配置済み。変更せず100%のサイズでスライス。
- サポートはまずOFF。スライスプレビューで宙に浮いた開始箇所がないか必ず確認し、あればその箇所だけ検討。
- E0017の再発を避けるため、まず1〜2本で試験。過去のG-codeを流用せず、最新版を再スライス。

## 3.5m本番用の構成（試験成功後のみ）
`01_PRODUCTION_STL` にある8種類を、ファイル名末尾の `PRINT_#X` の個数だけ印刷します。

| ファイル名 | 個数 |
|---|---:|
| V111_START_TOP_PRINT_1X.stl | 1 |
| V111_TOP_BOTTOM_PRINT_8X.stl | 8 |
| V111_BOTTOM_TOP_PRINT_5X.stl | 5 |
| V111_TOP_QLOW_PRINT_1X.stl | 1 |
| V111_QLOW_TOP_PRINT_1X.stl | 1 |
| V111_BOTTOM_QHIGH_PRINT_2X.stl | 2 |
| V111_QHIGH_TOP_PRINT_2X.stl | 2 |
| V111_BOTTOM_END_PRINT_1X.stl | 1 |
| **合計** | **21本** |

折りたたみ構成はv11と同じ4束（6+5+5+5本）。束どうしの着脱ジョイントはv11のキノコピン＋鍵穴式から変更していません。独立した小さな接続部品は0個です。

順序:
- A（6本）: START_TOP → TOP_BOTTOM → BOTTOM_TOP → TOP_BOTTOM → BOTTOM_TOP → TOP_QLOW
- B（5本）: QLOW_TOP → TOP_BOTTOM → BOTTOM_TOP → TOP_BOTTOM → BOTTOM_QHIGH
- C（5本）: QHIGH_TOP → TOP_BOTTOM → BOTTOM_TOP → TOP_BOTTOM → BOTTOM_QHIGH
- D（5本）: QHIGH_TOP → TOP_BOTTOM → BOTTOM_TOP → TOP_BOTTOM → BOTTOM_END

CAD上の折りたたみ外接寸法はA:177.5×11.5×26.9mm、B:177.5×11.5×24.6mm、C:177.5×11.5×22.5mm、D:177.5×11.5×19.0mm。モルッカーリv2.3本体の収納空洞より小さい**設計寸法**ですが、実機で収まるか、保持されるかは未確認です。

総距離は設計値3500mmであり、実測精度は未校正です。完成後に実際の巻尺で確認してください。

## 以前のv11をすでに印刷した場合
旧球状突起と、新しい開放溝は互換ではありません。着脱ジョイントの形状は維持していますが、回転端のある板は新しいSTLで再印刷が必要です。破損した旧パーツへの力任せの再装着はしないでください。

編集可能ソースは `03_CAD/generate_v11_1.py`、形状チェック詳細は `03_CAD/validation.json`。
