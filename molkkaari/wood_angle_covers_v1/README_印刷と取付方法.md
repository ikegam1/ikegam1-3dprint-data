# 純正木製モルッカーリ用・角度固定カバー（PETG / Adventurer 5M）

このデータは **市販・純正の木製モルッカーリ用**です。以前作成した3Dプリント製モルッカーリのジョイント突起との共用は保証していません。

## 何を印刷する？

木材断面の**厚さが約18mm**、高さが約32〜33mmの場合は、まず `Tactic_18mm/TIGHT` フォルダ内から以下を印刷してください。

1. `FIT_TEST_18.6mm_H33_print_first.stl` を**1個** → 木材にかぶるか試すための短い試験品
2. `MOLKKAARI_CENTER_180deg_x1_18.6mm_H33_PETG.stl` を**1個**
3. `MOLKKAARI_CORNER_45deg_x2_18.6mm_H33_PETG.stl` を**2個**（左右共通）

18.6mmがきつければ `Tactic_18mm/EASY` フォルダの内幅19.2mmを試してください。

**テストを終えて18.6mmで問題なければ**、単一STLファイル `MOLKKAARI_TACTIC_18mm_3PIECES_220mm_plate.stl` を読み込むと、中央用1個・45°用2個がAdventurer 5Mの220×220mm範囲に配置済みで読み込めます。STLは最終的にOrca-Flashforgeなどでスライスしてください。

木材断面の**厚さが約17mm、高さが約30mm**の製品向けには `Other_17mm` のTIGHT/EASYを使います。木材の正確な厚さをノギスで測ることを推奨します。

## 設計寸法（mm）

| 仕様 | 厚さ18mm品向け | 厚さ17mm品向け |
|---|---:|---:|
| 木材の想定厚さ | 18 | 17 |
| カバー内幅（きつめ/TIGHT） | 18.6 | 17.6 |
| カバー内幅（ゆとり/EASY） | 19.2 | 18.2 |
| カバー全高 | 33 | 30 |
| 天板/側壁厚 | 2 | 2 |
| 関節部の局所追加逃げ | 幅片側 +1.3 | 幅片側 +1.3 |
| カバーの中心から各側への長さ | 50 | 50 |
| 中央カバー全長 | 100 | 100 |
| 端部カバーの曲がり角 | 45° | 45° |

**注**：カバーの高さ33mmは、木材が33mmの場合も、地面側に2mm程度の空間ができるよう天板と側壁の厚さを配置しています。30mmタイプについても同様です。上から差し込む構造なので、底面に板はありません。

## 印刷設定の目安（PETG）

- Flashforge Adventurer 5M、0.4mmノズルを想定
- レイヤー高：0.20mm
- ノズル温度：235〜245℃（フィラメントメーカーの指定を優先）
- ベッド温度：75〜85℃（フィラメントメーカーの指定を優先）
- 外周：4〜5周
- トップ／ボトム：5〜6層以上
- インフィル：20〜30%
- 速度：外周40〜60mm/s程度から試す
- サポート：**不要**
- ブリム：**4mm推奨**（縦に長い側壁の反り対策）

**重要：STLは印刷用に上下反転済みです。** スライサー上では天板の外面が造形プレートに接し、コの字の開口が上を向きます。印刷後に上下を裏返し、カバーを**木材の上から**かぶせて使用します。勝手に「最適な面に配置」を再実行しないでください。

## 取付方法

1. 純正木製モルッカーリを広げ、中央2本を直線（180°）にそろえます。
2. `CENTER_180deg` を上からかぶせます。布ヒンジに干渉するときは無理に押し込まないでください。
3. 左右端の木片をそれぞれ手前に約45°曲げます。
4. `CORNER_45deg` を左右の接続部に1個ずつ上からかぶせます。左右で同じ形状を使えます。
5. 収納するときはカバーを外してモルッカーリを折りたたみ、別々に持ち運べます。

## 注意・未検証事項

- 市販木製モルッカーリには製造差があり、木材の厚さ・高さ、角部の面取り、布ヒンジの貼り位置が異なることがあります。
- ここに含むデータは**公表された代表寸法からの設計試作品**であり、所有する実物での装着・耐久試験は実施していません。まず小さいテストピースで寸法確認してください。
- 布ヒンジが大きく出っ張る個体は、その部分が干渉する可能性があります。逃げ部を追加設計する必要があります。
- 取り付けがきついときは無理に押し付けず、19.2mmタイプへ変更してください。緩い場合は18.6mmタイプを試し、必要なら薄い布テープを内側に貼って微調整してください。
- 布テープ付きの純正モルッカーリ自体を分解する必要はありません。
- PETGは屋外の炎天下で変形することがあるため、車内放置などを避けてください。

## ファイル構成

- `Tactic_18mm/TIGHT`：木材厚18mm用 内幅18.6mm（推奨試作品）
- `Tactic_18mm/EASY`：木材厚18mm用 内幅19.2mm
- `Other_17mm/TIGHT`：木材厚17mm用 内幅17.6mm
- `Other_17mm/EASY`：木材厚17mm用 内幅18.2mm
- 各フォルダに中央用、45°用、試しはめ用のSTLが入っています。
- ルートに `...3PIECES_220mm_plate.stl`：18.6mm版3個をAdventurer 5M用に配置したSTL
- `EDITABLE_TACTIC_18mm_*.step`：18.6mm版のSTEPデータ
- `create_original_molkkaari_covers.py`：他の寸法に調整するためのCadQueryソースコード
- `geometry_validation.json`：出力データのサイズとメッシュのチェック結果
- `preview_joint_covers.png`：取り付け方の概要図
- `AD5M_print_plate_preview.png`：造形プレートへの配置図
