# カップホルダーv1.3：テーブル下へ大幅移動

今回の修正：中央テーブルv0.9の前縁はY=-81mmです。カップの下部中心をY=-76.0mm、上部リング中心をY=-95.7mmとし、底部は概ね半分をテーブル下へ移しました。従来v1.2では下部中心Y=-146mmでした。カップ底部の高さZ=-171.0mmは旧版と同じです。

**重要：** テーブルと干渉せず500mlペットボトルを出し入れするため、カップは**15°前方（外側）へ傾斜**しています。以前の6.5°内向きでは「半分をテーブル下」かつ「同じ高さ」ではボトルがテーブルにぶつかります。今回、カップ/ボトルの重心は概ね旧版よりテーブル側へ約29mm近付きますが、傾斜自体は外向きです。

- カップ内径：83mm（旧85mm）。外径93mm、網形状のまま。
- 接続：v1.2と同じ113mm幅のU字サドル（v0.9テーブル厚6mm用）。ネジや小さな別体パーツなし。
- 500ml想定モデル：直径80mm、高さ220mm。着座〜220mm引き上げの間を5mm刻みでCAD照合し、ボトル/テーブル/保持部の干渉ゼロ。
- v0.9中央天板模擬体との差し込み経路を検査済み。実物での嵌合/耐荷重は未検証。
- STL：`STL/CUP_v13_500ml_HALF_UNDER_TABLE_BACKSHIFT_MESH_AD5M_PETG.stl` だけ印刷すればよい。STEPと生成Pythonも同梱。
- Flashforge Adventurer 5M 0.4mmノズル PETG、0.2mm積層、外周4〜5周、ブリム4〜6mm。カップ底が接地する向きに調整済み。
- U字サドルの突き出しにはサポートが必要になる場合があります。スライサーのレイヤープレビューで確認し、取り外し時は薄い部位に力を掛けないこと。
- 保持力・固定クリップの抜け止め・飲料入り500g静荷重・三脚の転倒は未検証。初回は安全な場所で空ボトルから。

## 印刷時の消費量・支持条件
- STLメッシュ体積からのPETG樹脂重量の参考値は約299g（密度1.27g/cm³を仮定）。スライサーが算出するフィラメント長・支持材量を優先してください。
- 向きはカップ底面がベッドに接地するよう調整済み。中央テーブル用U字接合部の下にはサポートが必要になる場合があります。上方の幅広サドルにサポートが直接一体化して取りにくくならないよう、**レイヤープレビューを確認してから印刷**してください。
- 中央テーブル本体の再印刷は不要。変更はドリンクホルダー1パーツだけです。
- 実物での取り付け・500g荷重・振動・転倒安全性は未検証のため、まず空ボトルで差し込みを確認してください。
