# 推奨印刷設定 — 3.5m測定具の連結ヒンジ v13（試験用）

> **このモデルは2節・3節の連結試験のみ。3.5m本体の完成STLではありません。** 可動性・直線性・収納性は実機未検証です。

## 前提
- プリンター：Flashforge Adventurer 5M
- ノズル：**0.8mm（実物とスライサーを一致させる）**
- フィラメント：TPU 95A（Orca-Flashforge `Generic TPU` を編集）
- 先に印刷するファイル：`PRINT_FIRST_2_RAILS_CAPTIVE_HINGE_0p8_TPU.stl` だけ。
- **モデル倍率100%。** STLを自動で倒したり、別パーツに分割したりしない。

## 暫定設定（0.8mmノズル）
| 設定 | 初期値 |
|---|---|
| ノズル温度 | 材料メーカーのTPU 95A推奨温度を優先 |
| ベッド | 45〜55℃程度を目安（プレート・材料指定優先） |
| レイヤー高さ | **0.24mm** |
| 線幅 | 0.88〜0.95mm程度 |
| 初層速度 | **10〜12mm/s** |
| 外壁速度 | **15〜20mm/s** |
| 内壁・インフィル | 20mm/s程度 |
| 最大体積速度 | **1.5〜2.0mm³/s**から開始。安定なら増やす |
| リトラクション | **0mm**で詰まりの切り分け（糸引きが増える可能性） |
| 自動サポート | **OFF** |
| ブリム | **OFF**（ヒンジ部へつながると可動不能になるため） |

## 重要：印刷方向
本体は一般的な薄いリボンとは異なり、**幅8mmを縦に立て、厚さ約1.6mmの端面をプレートに接地**した姿勢です。STLはこの向きで保存されています。

0.8mmノズルの線幅に近い薄い立ち上がりのため、ベッド密着が不安定になる可能性があります。むやみにブリムやサポートを増やしてヒンジを塞がず、失敗する場合はモデル自体を見直すこと。

## サポートと可動部
- 回転軸と受けリングは**印刷時から別々の固体が捕捉された状態**。自動サポートはOFF。
- 関節下面には**CADに組み込んだ小さな切り取り支柱4本**があります。
- スライスプレビューで**軸とリングの隙間が樹脂で埋まっていない**ことを確認。
- 印刷後は冷ましてから外し、支柱4本だけニッパーで切除。無理に回さず、小さな力で動くか確認。

## 試験の合格条件
1. 2節が回転し、軸が上下方向の力で脱落しない。
2. 回転時に積層割れ・固着・支柱の残りがない。
3. 2節を床に置き、左右に蛇行せず直線になる。
4. 3節試験を行い、折り重ねた状態から伸ばしても直線性が保てる。

**3.5mの距離精度、18節の折り重ね、モルッカーリ内への収納は未達成の設計課題**です。試験が通るまでは大量印刷しないでください。
