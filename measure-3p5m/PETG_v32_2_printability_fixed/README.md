# v32.2：本体STLの実印刷に関わる不具合を修正（PETG・0.4mm）

**重要：実機で完成を保証する版ではありません。** v32.1のCADを検査し、物理的に印刷できなくなる原因を2つ修正しました。ChatGPTで生成したZIPは `molkkaari_PETG_0p4_v32_2_PRINTABILITY_FIXED.zip`。**STL・STEPのバイナリはこのGitHubページにはまだアップロードしておらず、ZIPに同梱しています。**

## 修正した実不具合

1. **Z=0接地ミス**：v32.1の一部の捻じり板は印刷面より**0.679mm下**にあり、CAD全体をZ方向に補正した結果、ほかの板や印刷内蔵支柱が浮く問題があった。v32.2では板の断面位置を修正し、**全ての独立メッシュが印刷面Z=0へ接地する**ことを確認した。
2. **根元四角リングの開口ミス**：穴が外周より7mm片側にずれ、閉じた輪ではない形だった。外周32×47mm／内側24×39mmで**閉じたリング**に修正し、穴内部が実際に貫通し、周囲4方向が繋がっていることを検査した。
3. **切欠き強度**：板に直接切り抜く三角穴の尖った角を**半径約0.45mm**で丸めた。独立した三角輪を付け足していない。
4. **板中央**：両端厚1.6mm → 中央厚1.2mmへ緩い厚み勾配。薄い一箇所だけが折れないよう広範囲で変化させた。
5. **根元との一体性**：四角リングと最初の板を繋ぐ橋部分を増やし、**約1.5mm実体積の重なり**を設けた。
6. **サポート**：スライサーの自動サポートはOFF、CADに内蔵された支柱は引き続き使用（4本/2枚テスト、28本/束、全84本）。板との垂直離隔は0.30mmへ調整。**剥がしやすさは未検証**。

## 実機検証が必要な問題（現時点で本体の印刷は慎重に）

- **収納：未合格。** 三角穴部の最大幅は約12.6mm。過去のモルッカーリ中空幅の設計値約11mmより大きい。実際の折り畳み姿勢で向きが変わり収納できる可能性はあるが、まだ保証できない。幅10mm/11mm/12.6mmの**簡易物理ゲージ**を同梱している。
- **測長：未合格。** 3,500mmはCAD上の節間折れ線の総和。根元リング、各C字着脱部、自由に動く連結部の遊びを含め、**軽く張った実測3,500mmにはまだ校正できていない**。公式測定には使わない。
- **支柱の除去：未検証。** 実際のPETGで融着せず剥がれるかどうかは2枚テストで確認する。
- **強度と寿命：未検証。** 三角穴周囲のPETG疲労、折りたたみ時の引っ掛かり、C字フックの自然脱落や曲げを実機で確認。
- **スライス経路：未検証。** 0.20mmレイヤーで1層目に全ての支柱と板が形成されること、空中開始がないことをOrca-Flashforgeで確認してから印刷する。

## 推奨試験順

1. 収納幅の簡易ゲージを印刷してモルッカーリ内側で干渉する幅を調べる（実際の折りたたみ状態の保証にはならない）。
2. 2枚連結試験片でサポートの剥がしやすさ、自由な可動性、穴縁の強度を確認。
3. 問題がなければ第1束を印刷し、折りたたみ状態で収納できるか実物確認。
4. 収納可能と分かってから第2・第3束へ進み、張った全長を**巻尺で3,500mmに校正**する。
