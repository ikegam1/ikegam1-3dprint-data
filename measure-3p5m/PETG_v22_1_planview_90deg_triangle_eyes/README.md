# v22.1 — 修正版：隣接する板の「上面視90°」配置＋三角穴一体ジョイント

> **状態：2枚のCAD成立確認用モデル。印刷推奨STLではありません。** 前版v22で90°を「板全体を長軸周りに立てる角度」と誤解した点を訂正しています。

## 正しいイメージ

**ビルドプレートを上から見たとき、隣り合う板の長手軸が90°** となるL字形の配列です。両方の**長い板部分はベッドに平行**のまま。片方の三角穴付き端を少し浮かせ、もう片方の端を立体交差させ、**細い首や別体ジョイントを使わず**、穴と穴で印刷時から連結しておく構想です。

PETG・0.4mmノズル、Flashforge Adventurer 5M。板を幅広・厚めにしてよいという要望を反映し、短い試作では板幅9.5mm、板厚2.8mmとしました。穴の周囲も幅広い本体と一体化しています。
