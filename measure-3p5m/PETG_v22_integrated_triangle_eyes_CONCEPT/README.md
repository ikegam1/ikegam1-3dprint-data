# v22 — 板端一体・三角穴インターロック方式（構造検討用CAD）

**状態：2枚のCAD概念試作。印刷可能な完成版ではありません。** 3.5mの26枚連結STLは未作成です。

## 提案のポイント

v21は板に別の八角形の輪を付けているため、荷重を受ける接続首が破損リスクとなります。v22は**板の端を幅広い目玉形状に拡張し、その中を三角穴にして、隣の板の三角穴と立体的に絡ませる**構造です。使う際のはめ込み操作や独立した部品はありません。

PETG / 0.4mmノズル / Adventurer 5Mを前提とします。三角穴の角は半径約0.65mmに丸め、鋭角を避けています。

45°と90°は**板の長辺（X軸）まわりに回転させた角度**です。板を縦方向に長く立てる配置ではありません。90°で長辺を接地する配置なら長手方向（引張方向）をXY平面内に維持できますが、曲げ・ねじれ時の層間破壊の有無は試験が必要です。

## 成立条件と製造上の注意

- 印刷時の2枚の三角穴は互いに通り抜けた状態で、別固体同士に隙間があります。手動で連結する作業は不要です。
- FDM印刷では**傾斜した穴の裏面と、プレートの接地面の少なさ**が課題です。密着用の一時タブ、剥離可能な局所サポートや傾斜角をさらに検討する必要があります。
- **今ある45°／90°のSTLは支持材・接地タブまで完成した「実印刷推奨STL」ではありません。現段階で印刷しないでください。**
- 成功したv21の「両端2.8mm→中央1.5mmの緩い薄肉化」は**この短い50mm試作には未反映**。本体版へ展開するときに継承します。
- **3.5mの本体への展開、26枚の互い違いの向き、220mm角への同時配置、サポート除去、強度、最終長さの校正、モルッカーリ中空への収納は未検証**。
- 旧v21は既に26節すべてを220mm角内に配置できているため、90°配置による印刷枚数増加は現時点で決定的な利点ではありません。先に強度とサポートの容易さを優先します。
