# v20 PETG 0.4mm：鎖の首折れを改善する幅広補強版（実機テスト待ち）

> **重要：v19の26節本体は2026-10-30に印刷で首の部分が多数破断し、不合格。v19は本番印刷しないでください。v20はその破損箇所を改めた試験版です。強度・可動性はまだ実物で未確認です。**

## 改訂理由

写真では、棒の本体よりも、八角形の輪につながる**細い接続腕の根元**が折れています。v18の小型試験では連結が成立していましたが、実物長の板を持ち上げたり折り畳むと接続部に曲げ荷重が集中しました。

## v20 の補強

- **八角形の輪と閉環が立体的に絡み合う構造を維持**。以前のv18と同じリンク形式。
- A側：幅狭の橋状腕を、板の長さ方向に広がる肩形のガセットへ変更（元の輪の位置関係を維持）。
- B側：長さ方向に約15mm伸びた細い接続腕を廃止。底部に幅広の三角形ガセットを作り、約2.8mm厚へ補強。
- 根元の**内寸24×39mm角丸四角リング**と最初の板の付け根も広く変更。
- 先端の錨と26節・25関節、追加の別体ジョイント部品0個、PETG・0.4mmノズルは維持。
- CADでは、26節が閉じたSTLメッシュ（26成分）、干渉体積が0、印刷サイズ約205.34×204.40×13.52mmでAdventurer 5Mの220mm以内に収まることを検証。

**注意：** 輪そのものの材料断面は従来のままです。付け根を強化すると、輪の別の箇所へ破断位置が移る場合があります。また補強によって回転自由度が狭くなる可能性もあります。

## 印刷順序

1. **`01_PRINT_FIRST_TWO_RAILS_ONE_REINFORCED_JOINT.stl`**：実寸の棒2本でジョイント1か所だけを確認。旧v18の短い試験とは違い、実際の棒の長さによる荷重を確認できます。
2. 支柱3本を除去し、輪の回転・畳みやすさ・軽い曲げ／引っ張りで首が割れないかを確認。
3. 合格後、**`02_SECOND_TEST_THREE_RAILS_TWO_REINFORCED_JOINTS.stl`**：左右のジョイント2か所の可動範囲・収納性を確認。
4. 両方合格して初めて `FULL_26_REINFORCED_SHOULDERS_PETG_0p4_UNCALIBRATED.stl` の印刷を検討。

v18で成功したPETG・0.4mm用プロファイルを優先すること。ノズル変更や材料設定を混同しないこと。

## 未確認事項

- PETGによる**実際の曲げ強度・疲労・衝撃耐久**は検証前。
- 輪自体の破損と回転範囲の不足が起こり得る。
- **3,500mmは実測校正前の目標値**。巻尺で張った時の実測が必要。
- **モルッカーリ中空への収納は実物未確認**。
- 本体26節には柱が75本。切除負担が大きく、量産前に試験すること。
