## 印刷後の取り扱い

1. プレートを冷まし、全体を支えながら外す。
2. 25関節にある切除式支柱75本をニッパーで取り除く。輪そのものを傷つけない。
3. 25関節がすべて可動することを確認。無理に回して折らない。
4. 根元リングをモルッカーリへ掛け、先端の錨まで**同じ程度の軽い張力**で伸ばして実測。
5. 実測長が3,500mmと異なる場合は、CADの節ピッチを補正して再出力する。**未校正のまま公式な距離の判定に使用しない。**
6. 収納は2束以上に折り分けて、実際の本体中空へ収まるか確認（可動リングの高さは約13.5mm）。
