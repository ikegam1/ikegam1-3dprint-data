# v32.1 — 三角穴を板材から直接切り抜く＋STL内蔵サポート（PETG・0.4mm）
**実ファイル作成済み：** 3束×8枚の本体STL、2枚連結試験STL、CAD用STEP、生成ソース、検証JSON。**ただし実機印刷成功・3.5m長さ・収納は未検証**。

## ユーザーが確認したサポート条件
**スライサーの自動サポートはOFF。一方、STLの設計時に入れておく切除用サポートは許容される。** 以前の「切除用サポートも0本必須」という理解は誤りだったため撤回する。

## 設計方法・以前の破断からの変更
- **一つながりの板材の全幅を先に作り、そこから三角穴をBoolean cutで貫通切除**。別の輪の押し付け、後付け、細い連結首は使用しない。
- 2枚の穴境界同士が非分離に絡んだ状態をCADで確認（Gaussリンク数約-1.0）。3束それぞれの7関節すべてのリンク数も±1.0を確認。
- 自動サポートなしで造形するため、縦向きの板部分の下に**CAD内蔵の独立支柱4本/関節側**を配置。小型2枚テスト4本、各束28本、合計84本。支柱の先端は板から**0.28mm離す**。
- 細いC字フック同士で束間のみ着脱。根元の四角リングと先端の錨は維持する。
- STLのメッシュ検査、サポート／本体の体積干渉検査、造形範囲の確認を実施。

| 2枚連結テスト | 63×67×16.88 | 2 | 4 |

**重要な限界：** 実使用時3,500mmは未校正（経路長3,500mmのみCAD確認）、折りたたみ後の収納寸法は未検証。穴付近の局所最大幅約12.6mmは従来の収納内幅約11mmを超える可能性がある。根元リングは外部にはみ出してよい。**収納確認まで本体の大量印刷は推奨しない。**

推奨初期設定：PETG／0.4mmノズル、レイヤー0.2mm、初層15mm/s、外壁25mm/s、**スライサーサポートOFF**、モデルの自動分離と再配置OFF、倍率100%。まず2枚テストで支持柱を剥がしやすいか、穴の縁が割れず自由に動くか確認する。
