# v25：板に直接開けた三角穴 ＋ 束間の一体型S字フック（PETG／0.4mm）

## 対象と状態

ユーザーが指定した**3.5mを3束に分ける計測器のうち、束と束の着脱箇所だけ**を改めた試作です。**内部の鎖式三角穴を最初から連結して印刷する問題は、このテストではまだ解決していません。** v24の内部連結STLを本番印刷用と考えないでください。

## 接続仕様

- 一方の端は**薄く平たい板そのものに三角の貫通穴**を開ける。別に盛り上げた三角リング、細い首、後付けのリングは無し。
- 相手側は**板の端から連続して造形するS字状フック**。紛失する独立のS字パーツを増やさない。
- この着脱機構を使うのは、3束の**間の2か所のみ**。束内部の複数の節は連結したまま保持する。
- 穴周りの端部最大幅約10.2mm、板本体幅9.2mm、厚さ1.8mm。現在のモルッカーリ収納内幅（仮11mm）に対し余裕が小さいため、現物確認が必要。
- S字フックの保持力や繰返し着脱疲労は未検証。軽く抜けるならフック口を狭める設計や厚み・受け側の補強を見直す。

## Orca-Flashforge 推奨初期値

- PETG・0.4mmノズル、0.20mm積層、外壁25mm/s。
- **自動サポートOFF、内蔵支柱0、ブリムOFF**。
- 2部品は**別々で正常**。束同士はユーザーが手で引っ掛けて着脱するため、印刷状態で連結済みである必要がない。
- 印刷後にS字の先端を斜めに穴に入れ、軽い引張、ねじり、繰返し着脱で強度を評価。

## 最重要の未解決事項

1. **束内部の連結：板の母材を貫通する三角穴で、細首なし・全節が最初から機械的に連結済み・サポートゼロで印刷できる新設計がまだ必要。**
2. 3束の折りたたみ収納の外形を、実物モルッカーリ中空に照らして計測。
3. 鎖を軽く張ったときに3,500mmであることを実測校正。
4. S字フックがPETGの繰返し使用で折れず、使用中に自然には外れないことを検証。
