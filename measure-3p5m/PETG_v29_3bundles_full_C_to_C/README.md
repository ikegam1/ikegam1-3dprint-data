# v29 — 3.5m測定具：3束×9枚＋C字フック同士の着脱（PETG・0.4mm）

**3束分のSTL・STEP・設計Pythonを生成済み。** 旧v28の試験用の長い持ち手は除去し、C字端部の幅広い根元だけを本体の束間2か所へ組み込みました。根元の四角リング、先端の錨を維持しています。

> **重要：これはCADで完成した3束の本体候補です。実際の3.5m実測校正、折り畳み後の収納、PETGの無サポート造形は未検証であり、使用可能な完成品だと断言できません。** さらに内部連結はv24の垂直に立ち上がる三角アイを継承しており、「完全に平らな板に直接穴を抜く」希望に厳密には一致しません。

## 実データ

会話から `molkkaari_3p5m_v29_3bundles_C_to_C.zip` を取得できます。中には次の5つのSTL、3束のSTEP、再生成用Python、検証JSON、STLから作成した印刷配置図、説明書があります。

- `BUNDLE_01_9_PLATES_ZERO_SUPPORT_C_HOOKS.stl`：根元四角リング→Cフック
- `BUNDLE_02_9_PLATES_ZERO_SUPPORT_C_HOOKS.stl`：Cフック→Cフック
- `BUNDLE_03_9_PLATES_ZERO_SUPPORT_C_HOOKS.stl`：Cフック→先端錨
- `TEST_FIRST_2_PLATES_INTERLOCKED.stl`：束内部の2枚連結の短い確認用
- `TEST_HOOK_TO_HOOK_SHORT_GRIPS.stl`：旧テスト片を縮めたC字端部同士の確認用

**GitHubにSTLバイナリをアップロードした状態ではありません。ZIP内にあります。**

## CAD検証

| 3束の区分 | 造形時サイズ（mm） | 閉メッシュ |
|---|---|---|
| 1：四角リング→C字 | 214×193×27 | 9体、全部正常 |
| 2：C字→C字 | 207.3×184.4×27 | 9体、全部正常 |
| 3：C字→錨 | 207.3×184.4×27 | 9体、全部正常 |

- 3束それぞれ9節のCAD部品同士の**体積干渉0**、造形範囲220×220mm以内。
- スライサー自動サポートOFF、STL内蔵支柱0。
- 部材幅8.4mm、Cフックの太い根元は最大約20mm。内寸24×39mmの根元リングは収納外へ出してよい。
- **連結節点の基準線長の合計3500mmは、実際の測定端点間距離ではありません**。フックの重なり・遊びを含めた張った状態の測長は未校正。
- **内部の三角アイは高さ27mm**。折り畳んだ収納断面とモルッカーリの中空内幅約11mmに入るかは未確認。太いフック端部を収納外に出す必要がある可能性があります。
- 内部の連結アイはv24の**自立する立体三角形**であり、純粋な薄い板の貫通穴という条件は未達。

## 推奨印刷条件と中止基準

Flashforge Adventurer 5M、PETG、0.4mmノズル、レイヤー0.20mm、初層15mm/s、外壁25mm/s、スライサーサポートOFF、内蔵支柱なし。既存のPETG成功プロファイルを優先。部品を自動分離・再配置せず、スライスプレビューで空中開始を必ず確認してください。

2枚連結の無サポート印刷可否、Cフック同士の着脱、収納断面と実寸3.5mが確認できるまで、3束を**実用品として一気に印刷することは推奨できません**。

## 過去版との違い

v28は長い持ち手を付けた着脱試験2本セットで130×79mm。**それは実際の連結部の大きさではありません**。v29はその余計な試験板を本体に持ち込まず、連結部だけを使っています。
