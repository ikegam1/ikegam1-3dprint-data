## CAD確認と残るリスク

- 3つの本体STLはそれぞれ**9枚の閉じた板と56本の閉じた支持柱**、合計65のwatertight構成要素。
- 異なる板同士のCAD上の体積交差は**ゼロ**。三角穴のA/B輪は閉環中心線のGaussリンク数約−1.000003を確認。
- 印刷範囲：最大1束目218×193mm。220mm角に収まるが余白が非常に少ない。
- 実際の長さは根元リング、Jフックの掛かり位置、錨先端、チェーンの遊び、PETGの反り等によって設計基準線と異なる可能性があり、**正確な3,500mmは未保証**。
- 内蔵支持柱が自動サポートなしで十分か、PETGの橋渡し印刷と柱除去の実機検証が必要。
- 着脱式Jフックは強固なロックではなく、組みやすさ優先。軽い引張りでも勝手に外れないか実物で評価が必要。

**旧v22.3/22.3.1の穴端幅34mmは不採用**。v23で穴端幅9.6mmへ小型化。内側へ収まるよう設計した候補ですが、収納完了の実機確認を意味しません。
