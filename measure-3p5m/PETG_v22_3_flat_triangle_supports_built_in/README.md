# v22.3：三角穴一体型2枚連結・切除しやすいサポート内蔵試験

**状態：PETG／0.4mmノズル向けの印刷用テストSTLを生成済み。実物では未印刷・未検証です。** 3.5m完成品ではありません。

## 前版v22.2からの変更

板の主要部分は**薄い平板**のままで、端部に三角形の貫通穴を直接開け、穴の周囲だけ約0.6mm補強する方式を維持。ビルドプレートを上から見ると、板の長軸同士が90°です。

今回は**サポートを別途生成しなくて済むよう、取り外し用の支柱をSTL内に20か所含めました**。

- A側：浮いた三角穴の外周下面と端部の立ち上がりを支える12か所
- B側：ねじれた端部3か所、縦向き三角穴の下辺3か所、上辺を側方から支える棚付き2か所
- 自動サポートは **OFF**。三角穴の中を大きなサポートで埋めないよう配置しました。
- 支柱は接地しており、上端とプレートの間には原則**約0.3mm**の隙間を取っています（一部は干渉回避のため約0.5mm）。縦穴の上辺には短い横棚があります。
- 0.20mm／0.30mmの隙間を比較できる**小さなサポート除去試験片**も用意しました。
- 支柱と板はCAD上で交差せず、すべて閉じたSTLメッシュです。**実機で接着せず外れること・全オーバーハングが成功することは未保証**です。

## 推奨印刷の順番

1. `OPTIONAL_FIRST_SUPPORT_GAP_TEST_020_030.stl` で、先端0.2／0.3mm隙間の支柱をPETGで外せるか確認。
2. `PRINT_FIRST_V22_3_TWO_INTERLOCKED_PLATES_SUPPORTS_BUILT_IN.stl` を印刷。**自動サポートOFF、部品の自動分離・再配置OFF**。
3. 冷却後、支柱の根元をニッパーで切り、残りを丁寧に外す。穴の周囲やプレート本体を無理に曲げない。
4. 2枚の可動性・強度・支柱除去に成功したら、実寸2枚とv21の中央薄肉構造、モルッカーリ根元角リング・先端錨の統合へ進む。
