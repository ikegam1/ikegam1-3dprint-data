# v32.3 — 収納幅を抑えた直接三角穴・補強版（PETG / 0.4mm）

**現状：3束の印刷用STL、2枚連結試験、収納幅ゲージ、S/C字着脱端部テスト、STEP・生成ソース、寸法とCAD干渉の検査レポートを作成済み。実機での収納・耐久・3,500mm測長精度はまだ未合格。**

## v32.2からの実際の変更

- 連結部の板材最大幅 **12.6 → 10.8mm**、印刷時の最大高さ **16.2 → 15.05mm**。
- 板端の材料厚 **1.6 → 1.8mm** に増やし、中央のみ **1.2mm** まで緩やかに薄く。
- 三角穴は**連続した板材そのものをBoolean Cutで貫通させる**。別体リングや細い首はなし。角は半径約0.45mmの丸め。
- 三角穴の位置・形と立体交差を再設計し、**全21関節の部材間最小距離をCAD上で0.500mm**に。3束とも板同士の体積干渉0、閉じたメッシュ。
- 旧版の部材間衝突に対応し、蛇行レイアウトの最終部を調整。3束それぞれ8枚、CADの配置経路合計は3500.0mm（引き伸ばした時の実測長とは別）。
- 束間C字フックをv30の形状から3%縮小：端部外幅**約10.727mm**。2個の着脱テストを同梱（保持力・嵌合は未検証）。
- 内蔵支柱は各束28本／テスト4本、縦隙間0.32mm。**Orca-Flashforge自動サポートOFF**。内蔵支柱の実機剥離は未検証。

## 必ず残す未解決項目

1. **収納の合否は未確認**。モルッカーリ内幅の暫定11mmに対し最大穴部10.8mmなので公称総クリアランスはわずか0.2mm。PETG印刷誤差や内部フィン、8枚折り畳み時のかさばりを考えると収納できるとの保証にはならない。
2. **3.5mの実測値は未校正**。3500mmは印刷ベッド上の蛇行した節点間の経路長。使用状態の根元リング基点から錨先端の距離は、自由関節・C字フック2か所の遊びがあるため別途巻尺で実測が必要。
3. **実際のPETG造形やサポート除去、フック保持、三角穴の割れ・折り畳み寿命は未試験**。CAD上の連結と非干渉は耐荷重の証明にならない。
4. 印刷前にOrca-Flashforgeで全層のスライス経路、ビルドプレートへの接地、宙に浮く箇所、内蔵支柱が消えていないことを確認する。

## 推奨初期印刷設定

Adventurer 5M、PETG、0.4mmノズル、層高0.20mm、初層15mm/s、外壁25mm/s、内壁30mm/s、**自動サポートOFF**、モデル内蔵支柱は維持、パーツ自動分離・再配置OFF。ノズル・ベッド温度はフィラメント／プレートメーカーに従う。

**印刷順は幅ゲージ → 2枚連結テスト → C字着脱テスト → 第1束 → 残り2束**。第1束で実際の折り畳み収納を確かめる前に、第2・第3束を大量印刷しない。
