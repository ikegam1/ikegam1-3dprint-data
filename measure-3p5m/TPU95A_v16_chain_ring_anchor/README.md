# v16 — 鎖式3.5m測定具＋根元リング＋錨先端（CAD試験版）

**現在の状態：フルサイズSTLは生成済み。ただし、実機での印刷・可動性・測定精度・収納は未検証です。**

## 確定要件

- TPU 95Aのみ、Flashforge Adventurer 5M、0.8mmノズル。
- 使用者が毎回17か所のジョイントをはめる作業はしない。**最初から鎖の輪が絡み合っている構造**にする。
- 輪の復元力によってU字に戻る構造ではなく、自由に曲がる機械式の連結。
- **根元端：内半径30mm（内径60mm）**のモルッカーリ引っ掛けリング。
- **先端端：錨のシルエット**（左右の爪と先端の穴）。

## 印刷順と注意点

1. `TEST_02_INTERLOCKED_TWO_SEGMENTS_WITH_SUPPORT_POSTS.stl` だけを最初に印刷。
2. 鎖が溶着せず自由に動くか、支柱を**外から**ニッパーで切除できるか確認。
3. 必要なら `TEST_ROOT_RING_FIRST_SEGMENT.stl` と `TEST_ANCHOR_LAST_SEGMENT.stl` で端部を確認。
4. 2節テスト合格後のみ3節、フルサイズの順に検証。

**本体には関節25か所につき3本ずつ、合計75本の切除用支柱があります。** この手間が許容できない場合には、別の印刷方式に再設計し、本体を印刷しないでください。
