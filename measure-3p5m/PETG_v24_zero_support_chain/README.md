# v24：完全支柱なし・板端三角穴インターロック式（PETG 0.4mm）— CAD候補

**実際のSTLを作成しました。3束×9枚の本体候補と、2枚連結の印刷試験片があります。**
ただし、**実機でサポートなしの印刷が成功するか、折り畳んでモルッカーリに収まるか、実寸3,500mmになるかは未検証**です。完成品としては扱わないでください。

## v23との主な違い

- **支柱0本**：v23で問題だった168本の切除用支柱を廃止。自動サポートもOFFで印刷する想定。
- 板端の三角形貫通穴同士が、最初から立体的に連結したモデル。
- 三角穴を「印刷後に剥がす支柱」で支えるのではなく、板端から立ち上がる**自立する斜面と三角アーチ**の形に変更。
- 板幅8.4mm、厚さ中央1.0mm／端1.2mm。細い独立した接続首を廃止。
- 9枚×3束。束間は2か所の一体型Jフック＋受け穴。根元は内寸24×39mmの四角リング、先端は錨。
- 印刷時の高さが最大**27mm**なので、収納深さの暫定値29.4mmに近い。**収納時の折り畳み外形はまだ算出できていない**ので、収納できるとは断言できない。

| モデル | 造形時外形 | STLの閉じた構成要素 | 内蔵支柱 |
|---|---|---:|---:|
| 2枚テスト | 約55×55.5×27mm | 2個 | 0本 |
| 第1束 | 214×193×27mm | 9個 | 0本 |
| 第2束 | 180×174×27mm | 9個 | 0本 |
| 第3束 | 180×174×27mm | 9個 | 0本 |

- 各束8か所の閉環リンクを幾何学的に検査。概算Gaussリンク数は各関節で±1.0003。
- CAD上の板同士の体積干渉0。
- STLはすべて閉じたメッシュで、220mmの造形範囲内。
- 3束の**CAD配置基準線長**合計は3,500mm。ただし、張ったときの実測全長ではありません（リング・フック・錨・関節遊びの補正が必要）。

## 印刷設定と順番

1. **最初に `STL_PRINT/TEST_02_COMPACT_INTERLOCKED_TRIANGLE_EYES.stl` の2枚のみ印刷**。後処理なしで連結が自由に動くか、上端が崩れず造形できるか確認。
2. プリンターはFlashforge Adventurer 5M、PETG、ノズル0.4mm、積層0.20mm、初層15mm/s、外壁25mm/s、スライサーの**自動サポートOFF**、ブリムOFFから。温度は使用PETGの指定を優先。
3. **自動分離・再配置は禁止**。スライスプレビューで全層を点検し、空中開始の経路がないか確認。
4. 小型テスト成功後に第1束、続いて第2・第3束を印刷。既存モデルの数倍の印刷時間がかかる可能性がある。
5. 各束の折りたたみ外形を実際にモルッカーリ内側へ当て、3束を接続して一定の軽い張力で巻尺校正。必要なら再設計。
