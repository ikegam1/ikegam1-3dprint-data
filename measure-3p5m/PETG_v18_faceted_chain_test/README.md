# v18：直線主体の八角形ジョイント（PETG・0.4mmノズル用）

**状態：2リンク試験STLを作成済み。実機未検証。3.5m完成版ではありません。**

## 改訂した理由
以前のTPU 95A・0.8mmノズルの鎖型連結は、曲面が歪み、実物では印刷中に関節の2か所が破断した。TPUからPETG・0.4mmノズルに切り替え、支持しやすい直線主体の輪を検証する。

## 変更内容
- 横向きの輪：円形から**八角形**へ。厚さ方向の輪の材料幅は約1.8mm、角を落とした形状。
- 縦向きの輪：角を落とした多角形を採用。輪の材料幅は約2.1mm。
- 輪同士は**印刷時点で立体的に連結**した2つの閉環。後からはめ込む操作なし。
- CADの交差体積0mm³。ガウスリンク数の数値検査は**約-1.0003**、非分離の閉じた輪を確認。
- 最小2リンク試験片は約**38.34×14.10×13.52mm**。両方とも閉じたSTLメッシュ。
- 自動サポートOFFで試すが、**横向きの輪の下に3本のCAD内蔵・切除用支柱がある**（完全サポートレスではない）。

## テスト手順
1. `PRINT_FIRST_MINI_2_LINKS_0p4_PETG.stl` だけ印刷。
2. CAD内蔵の支柱3か所を外からニッパーで切り、輪に割れがないか確認。
3. 2つの輪が固着せず自由に回るか、軽い引張りや上下の荷重で外れないか確認。
4. 支柱の除去と可動性に成功すれば、v17の四角い根元リング（内寸24×39mm）・錨型先端・26節へ構造を展開する。**v17本体の大量印刷は今の段階では推奨しない。**

### 限界
八角形にしただけで空中に浮く輪がなくなるわけではない。スライス時の支柱と輪の接続、可動部の隙間を確認。PETGは固着後に無理に動かすと破損し得る。全長3.5mの長さ校正、収納時の厚さ、印刷完走はまだ検証していない。
