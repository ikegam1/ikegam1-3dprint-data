# v15.1 — TPU 95A 鎖式ジョイントのサポート除去改善（試験版）

## 背景

v15の2リンク試作は、0.8mmノズルでTPU 95Aを印刷すると**一般的なサポートが強く固着し、鎖を評価できない**という実物の結果が報告されました。v15で必要だった大量のツリーサポート方式は採用しません。

## 今回の変更

- 垂直リンクを**傾斜約45°以上の山形リング**に再設計し、リング上端に大きな水平オーバーハングが生じにくい形状に変更。
- 水平リンクの一時支持には、**外側からニッパーで切除する9本の細い支柱**のみをCADに含める。一般的なサポート材を剥がすのではなく、切断して除去。
- **スライサーの自動サポートはOFF**。モデルの向きはSTLを読み込んだ状態を維持。
- 2個のリングは本当に連結している：CADでGaussリンク数 **約 -0.9977**、リング同士の実体積交差 **0mm³**。
- STLは閉じたメッシュで、最小2リンクの造形外形 **約21.75×17.16×16.27mm**。棒付き2節は **約153×17.16×16.27mm**。
- **注意**：サポートなしで必ず印刷できること、柱が容易に切れること、リングが癒着しないことは実機未検証。

**重要**：スライスプレビューで細い支柱・接続部が消えたり、オレンジの輪の上端が崩れそうな経路になっていないかチェック。0.8mmノズルで1本線の柱が造形されない場合は印刷せずモデル変更が必要です。

## 印刷後の確認

1. 十分冷ましてから外す。
2. **青い輪の外周にある9本の支柱を外からニッパーで切る。輪そのものは切断しない。**
3. TPUの固着を無理に引き剥がさず、両リングが自然に回転できるか確認。
4. 上下・ねじり方向に引いても外れず、折りぐせの復元力なく可動するか確かめる。
5. 2リンクで成功した後に3リンク以降とモルッカーリ収納へ進む。

## 未解決事項

**3.5m完成版ではありません。** 全18節の配置、収納、長さの校正、TPUの伸びによる誤差については未解決です。支柱も印刷時の必要最低限の支持方法を試験している段階で、完全なサポートレスとは呼びません。
