## 旧版v12からの変更

旧U字折り返しは直線に戻しても蛇行するため、**今回は各端面にキノコ状の凸頭と受け口を追加**。伸ばした際に隣の節を凹凸ではめ込み、直線位置を維持する狙いです。細いU字は切れない連結用のテザーとして残ります。各接続のスナップを毎回はめ込む必要があります。引っ張るだけで自動的に真っすぐになる機構ではありません。

## 重要：印刷の順番

**長い本体を先に印刷しないこと。** 初めに2節（72mm/節）を印刷し、連結可能か、軽く引いても外れないか、床に置いて真っすぐになるかを確かめます。次に3節試験で2か所の端面ロックと折りたたみを確認してから、フルサイズ印刷に進んでください。

薄いU字部分は0.96mm = 4層、通常部分は1.20mm = 5層をスライスプレビューで確認してください。0.8mmノズル幅では凹凸が潰れる恐れがあり、スナップのフィットは実物試験が必要です。

## 合格条件

1. 全関節が外れない一体形状で完成し、各凹凸が塞がっていない
2. 2節、3節のロックが無理なく入る
3. 地面に置いて手を離しても、実用上十分に一直線を維持する
4. 広げて測って**3,500mmになるか**校正する（引っ張るとTPUが伸びます）
5. 折りたたんだ束がモルッカーリの収納空洞（内幅約13.6mm×内高約30.6mm）に実際に収まる

**CADとSTLは形状の一体性・閉メッシュ・220mm範囲のチェックに合格しましたが、上記1〜5の実機合格は未確認です。**

詳しいデータはChatGPTから生成したZIPを参照。GitHubには、バイナリSTL/STEPのアップロードが確認できるまで、入ったと誤認しないよう**設計仕様と印刷設定のみ**を先に公開します。
