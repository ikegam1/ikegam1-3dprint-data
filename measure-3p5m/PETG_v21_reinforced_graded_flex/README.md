# v21 — 鎖ジョイント補強＋中央をなだらかに薄くしたPETG製3.5m計測具

**状態：CAD・STL作成済み／実機強度・可動性・距離精度は未検証。** v19の細い首は実機で多数破断。v20は試作設計段階。v21もフル26節の印刷前に実寸2節で検証が必要です。

## 今回の仕様

- 材質：**PETG**／ノズル：**0.4mm**／Flashforge Adventurer 5M用
- 鎖はv18で成功した**八角形＋面取り多角形の閉環リンク**を維持し、追加の別体ジョイントなし
- **輪と板の付け根**：A側ガセットの板への重なりを約4→10mm、B側を約6→11mmへ増加し、幅広い肩で荷重を分散
- **板の中心に向かって徐々に薄く**：両端2.8mm、中央1.5mm。急な溝を避け、余弦曲線でゆるやかに連続変化。幅5.4mm、長さ112.5mm
- 根元の角丸長方形リングは内寸**24×39mm**、先端は**錨型**
- 26節・25関節。関節には各3本、合計**75本の切除式支柱**（自動サポートはOFF）
- CAD／STL：26節すべてwatertight、相互干渉なし、プレート上サイズ**約205.34×204.40×13.52mm**
- 3,500mmの**実測校正は未完了**。収納時の占有厚みも未検証

## 推奨テスト順

1. `00_TEST_SINGLE_GRADUAL_THINNING_RAIL_NO_LINKS.stl`：板の中央が軽くしなるか、白化・亀裂が発生しないかチェック
2. **`01_PRINT_FIRST_2_FULL_RAILS_AND_THIN_CENTER.stl`**：実寸の板2本＋ジョイント1か所で、支柱を切って可動性・曲げ強度を確認
3. `02_NEXT_3_RAILS_JOINTS_AND_THIN_CENTER.stl`：2か所の可動性、折り重ねや収納の実用性を確認
4. すべて合格してから `FULL_26_V21_GRADUAL_CENTER_FLEX_PETG_0p4_UNCALIBRATED.stl` を印刷

**PETGの1.5mm中央薄肉は、軽く弾性的に曲げる狙いです。180°に折り込む生きたヒンジとしては使用しないでください。** 強い折り曲げや繰り返し疲労で亀裂が入るおそれがあります。収納はなるべく鎖の関節の回転で折り重ねる方式を優先してください。
