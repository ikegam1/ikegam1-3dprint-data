# v26 — 束同士を一体型「S字フック ↔ S字フック」で連結

> **現状：PETG・0.4mmノズル用の印刷試験STL作成済み。着脱・保持力・疲労強度・収納適合は実機未検証。3.5m完成版ではありません。**

## ユーザーの修正要件

- 3束の間の**2か所の着脱機構はS字フック同士**。以前の「Sフック＋板端の三角穴」は束間接続には不採用。
- **フックは板端と同じ母材から連続して変形する形**。独立した小部品や細い首は作らない。
- 板端を少し大きくしてもよく、強度優先。
- 束内部は従来どおり板の端に開けた三角貫通穴による連結を目標とする。ただしこの内部連結のサポートレス量産構造は別途検証が必要。
- PETG、ノズル0.4mm、Flashforge Adventurer 5M。

## 作成したCADとSTL

- 板幅：9.2mm
- 接続部の幅広い肩：最大16mm
- フックの曲がり部分：材料幅5.2mm、厚み3.2mm
- 板の平たい部分：厚み1.6mm。フック側へ**段差なしで徐々に3.2mmへ厚く**する。
- 2端のフックは**同じS字形状**、片方を180°回して印刷する。**印刷時は別部品**で、使用時に手で引っ掛ける。
- **スライサーの自動サポートOFF、STL内蔵支柱も0**。両端とも底面は平らで、サポート用の浮いた機構を持たない。
- 印刷レイアウト：初回用2本セットで**約176×111×3.2mm**、長めの実寸に近い強度試験2本セットは**約194×111×3.2mm**。どちらも220mm以内。
- 4種のSTLはwatertightで、2本セットは2部品、単体は1部品。外形とメッシュはCAD・STLで検査済み。

## 実物確認の合格条件

1. 2つのS字が無理に曲げなくても掛けられること。**2つのフックを必ず互いに接続する。**
2. 軽い引張りだけでは抜けず、意図的に角度を変えれば外せること。
3. 横方向・上下方向に力が加わっても不用意に脱落しないこと。
4. 何度か着脱・軽い曲げを行ってもフックの根元が白化・破断しないこと。
5. 大きくしたフック端を含めて**3束をモルッカーリの収納部へ配置できること**。内幅約11mmという仮値に対しフック外形の幅は大きいため、端部を外側に逃がす配置が必要かもしれない。

**注意：S字フックの輪郭があることだけでは機械的な十分な保持力の証明にはなりません。実物試験の結果で開口・曲がり・厚みを再調整してください。** 測定器全長3,500mmの精度も未校正です。
