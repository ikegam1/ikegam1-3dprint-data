# v30 — C字フック小型化＋板材に直接開ける三角穴（PETG 0.4mm）

> **v29の問題を修正するための短い確認用STL。3.5m本体の完成版ではありません。**

## v29からの訂正
- **v29は印刷不適合**。束内部のリングが付け足し形状で、強度不足を招くため再利用しない。
- 束内部に使いたいのは、**板の母材を切り抜いた三角貫通穴**。独立した輪を板へ追加しない。
- **束同士のC字フック**は旧v28の外幅約25.6mmが大きすぎたため、端部の最大横幅**約11.1mm**まで縮小。板からフックの根元は約9〜10mm幅の一体材料。
- フックの線材幅3.8mm、厚さ3.0mm、板本体幅9.2mm。小型化でむしろ細くなったので、**実際の引張・疲労強度は未検証であり、十分な強度を断言しない**。
- 三角穴は**板本体幅9.2mm、端部最大幅10.4mm、厚さ1.2mmから穴周りのみ2.4mm**。穴周辺は一体の材料として厚くしている。
- PETG／0.4mmノズル／自動サポートOFF／STL内蔵支柱なし。

## 印刷初期値

## 本体完成への残課題
**板に直接開けた三角穴を持つ薄板同士を、別体ジョイントなし・すでに連結済み・完全サポートレスで印刷する仕組みが未成立。** 2枚とも水平の平板のままでは閉環を互いに絡ませることはできず、印刷中の端部の立体姿勢を解決する必要がある。3束・全長3,500mmの張った状態での校正、折りたたみ収納外形、実機強度も未検証。

**v29をこの変更だけで完成品として再出力しないこと。**
