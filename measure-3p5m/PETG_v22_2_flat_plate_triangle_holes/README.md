# v22.2 — 薄い平板の端に三角穴を直接開ける連結案（CAD検討用）

**状態：CAD形状と2枚の立体的な連結を確認。未印刷、サポート・ビルドプレート接地未設計。STLはそのまま印刷しないこと。**

## ユーザー意図（修正後）
- **薄く平らなプレートの端に三角形の貫通穴を直接形成**する。
- 独立した輪を細い首で接続する構造は廃止（v19の首破断を踏まえる）。
- **三角穴の周囲だけ**軽く補強。板幅や端部の広がりは必要に応じて大きくしてよい。
- 印刷ベッドを上から見たときに**隣の板の長手方向と90°**で配置する。90°とは「板を立てる角度」ではない。
- それぞれの板の平板部分はビルドプレートと平行。穴の付近を局所的に持ち上げ・ねじり、閉じた穴同士が絡むようにする。
- TPUは使わず**PETG**、ノズルは**0.4mm**、Flashforge Adventurer 5M。
- 別体の小部品や毎回のスナップは増やさない。

立体連結を成立させるため、現時点では一方の穴付近を局所的に約90°起こしています。**最終的にもっと緩い角度・少ないサポートで印刷できるかは別途最適化**します。長い平板全体を90°立てる構造ではありません。

## 次に必要なこと

1. PETG 0.4mmで使える、剥がしやすい局所サポート／一時接地タブを設計。
2. v21の「板中央へ向かって滑らかに薄くなる仕様」を必要に応じて反映。
3. 2枚の実寸試験で、強度・可動性・サポートの除去を検証。
4. 合格後に全長3,500mm・根元の24×39mm角リング・先端の錨形状を反映して、収納と長さを実測校正。
