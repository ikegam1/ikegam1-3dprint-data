# v27 — S字フックの「板との付け根」を絞らない強化版（PETG / 0.4mm）

> **試験用STLの作成・メッシュ寸法検査済み。実際のS字同士の着脱、耐荷重、繰り返し強度、モルッカーリ内への収納は実機未検証。3.5m完成版ではありません。**

## v26からの重要変更

ユーザーから画像の赤線で**「フックの根元を細くする必要はない、強度優先」**との指示がありました。従来の肩からフックへ入る部分が局所的に絞られる設計を修正しています。

- 通常の帯幅は**9.2mm**を維持（収納部を不必要に太くしない）。
- フックに向かう付け根は**最大約20mm幅**に広げ、板の母材をそのまま連続させる。貼り付け式の輪や、細いネックは作らない。
- 旧v26の幅狭箇所付近（x=4mm断面）**約9.73mm → v27では約17.42mm**、x=6mm付近**約7.76mm → 約15.66mm**。ただしこれはCADの平面断面の長さであり、実際の破断荷重の測定ではない。
- フック形状の材料幅 **5.2mm → 6.4mm**。フック・根元の厚み**3.2mm → 4.0mm**。
- 帯の平面部分の厚み**1.6mm → 2.0mm**。根元へ向かって徐々に厚みを増やす。
- **束と束の間の2か所のみ**S字フック同士で着脱。2個とも同一形状で、印刷時は別体。後から引っ掛ける。
- 両パーツとも平置き。**自動サポートOFF、STL内蔵サポート0**。

## 試験上の注意

1. まず短い2本のS字同士を引っ掛けられるか確認。**開口部や接触部が太くなったことで、接続性が悪化していないか**も評価する。CADの形状とメッシュの検査は連結可能性の証明にはならない。
2. 引き伸ばし、横方向、上下方向での自然脱落と白化・折れを確認する。
3. 長い試験棒でも強度を確認。従来のv19破断が長い板の曲げモーメントによる可能性を踏まえる。
4. フックは通常の帯（9.2mm）より広い。モルッカーリの中空内幅が約11mmだと**端部をそのまま押し込むことはできない**。端部を収納外に逃がせるか別途検証。必要なら収納向きや形状を変える。
5. **束内部の三角穴による連結と、3束・3,500mmの完成版・実測校正はこのv27では未解決**。

強度を上げたCADであってもPETGの曲げ疲労、層間破壊や無理な嵌め込みが無いことは保証できません。
