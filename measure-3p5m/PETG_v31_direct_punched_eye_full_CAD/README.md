# v31：3束×9枚、板端の三角貫通穴一体型（PETG・0.4mm）

**実データ：3束分のSTL／STEP／CadQuery生成ソースを作成済みです。実機での無サポート印刷・収納・距離校正は未完了のため、実用完成品ではなく「3束のフルCAD候補」です。**

## v29からの修正
- 不採用の「輪を板先に貼り付ける構造」を廃止。板の先端シートに対して**三角形を直接貫通してくり抜く**方式へ変更。
- 一体となった端部の幅広いガセットで力を受ける。細い独立ネックは使わない。ただし実際の折り曲げ耐久は未試験。
- 束の内部では各9枚がCAD上で立体的に絡んだ状態。8関節×3束。
- 束間2か所はv30系の小型C字フック同士で着脱。根元の内寸24×39mm角リングと先端の錨は維持。
- 自動サポートOFFを想定、内蔵支柱0。**造形成功を確認したという意味ではない**。
- **重要：板全部が完全に平面という意味ではありません。** 三角穴のある最端部だけ立ち上げて交差させており、最大造形高さ約21mm。これは実物収納の懸念です。

CAD上で板同士に実体積干渉がなく、各STLは閉メッシュ。中心線のガウスリンク数は約+1.00001（穴同士が実際に絡んでいる指標）。

**3,500mmはCAD節点の経路長の合計です。** 一定張力で組んだ時の実寸ではありません。根元リング・フック・錨のずれと遊びがあるため、**公式計測には未使用**。折り畳み収納寸法も未証明で、過去のモルッカーリ想定内寸（約11mm幅×29.4mm深さ）との比較が必要です。

## 印刷初期値
- Flashforge Adventurer 5M、PETG、0.4mmノズル
- 層高0.20mm、初層15mm/s、外壁25mm/s、外壁線幅約0.42〜0.45mm
- スライサーの自動サポートOFF、**STL内蔵支柱0**
- ブリム基本OFF。板の自動分離・自動配置はOFF。温度はPETGメーカー指定を優先
- **まず2枚の穴付き連結テストで、実際に造形できて、リンクが固着せず、剥離作業なく動くか確認。** 失敗すれば本体3束を印刷しない
