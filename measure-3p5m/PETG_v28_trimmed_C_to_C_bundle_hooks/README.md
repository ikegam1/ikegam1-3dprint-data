# v28 — v27の先端下側だけをカットしたCフック同士の接続

**状態：PETG・0.4mmノズル用STLを作成、幾何・閉メッシュ・印刷範囲検査済み。フック同士の着脱と保持力は実機未検証です。**

## ユーザーによる変更指示
「先ほどの形状で先の方をカットするだけで良い」「単体のパーツ自体はS字ではなく、2つを連結したときにS字になるイメージ」。

## v27からの変更内容
- v27の**下側・2個目のS字カールだけ**を削除。上側のC字状フックを残す。
- 切断は元の中心線の **(22.9, -6.1) mm** で実施。形状の再設計はせず、v27のスプラインをその位置で切ることにより上側の曲線を維持した。
- **付け根の幅広い補強形状、板本体の幅9.2mm、厚み2.0mm、フック幅6.4mm、フック厚み4.0mm**はv27から変更なし。
- 入口と基部との単純なCAD上の距離は約9.8mm（相手の材料幅6.4mmに対し余裕がある狙い。ただし**実際に掛けられるという保証ではありません**）。
- 束同士は、**同じC/J形状の端部2つを向かい合わせて掛ける**。印刷時点では2個は別部品。別体フックや小部品は追加なし。

ZIPには編集用STEP、CadQuery生成ソース、v27との変更箇所を示した比較図、印刷配置図、幾何QA、日本語手順書も収録。GitHubは説明書を格納、STL/STEPバイナリ本体はこのZIPに格納。

## Orca-Flashforgeの初期設定
- 材料PETG、Flashforge Adventurer 5M、**0.4mmノズル**
- 層高0.20mm、初層15mm/s、外壁25mm/s、内壁30mm/s
- **自動サポートOFF、モデル内蔵支柱0**
- 100%スケール、温度はPETGメーカー指定優先

## 試験で確認すべきこと
- **同型Cフック2個で、S字になる向きに実際に連結できるか**。必要な開口、位置合わせ、ねじり方向を確認する。
- 軽く引いても意図せず外れないか、意図的に動かしたときには外せるか。
- 付け根・フックの白化／曲げ破断がないか。
- 束同士の着脱部に使うフックは最大外幅が本体幅9.2mmを超えるため、モルッカーリの収納状態を確認する。

**これは束同士の2か所に使う端部連結の試験モデルです。** 束内部の三角穴連結、3束統合、折り畳み収納、全長3500mm実測校正は別途未完成。これを完成版とはしない。
