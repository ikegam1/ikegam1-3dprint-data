# クッブ 室内練習用・全6面密閉の軽量モデル

## 形状
- 外寸：70 × 70 × 150mm。縁・角は1.5mmの面取り。
- 外側6面はすべて閉じています。開放面、蓋、キャップはありません。
- **このSTLはソリッドの形状**です。ただし、スライサーでインフィルを低くすることで、内部をほとんど空洞にして薄い外壁と少量の格子状補強だけを造形します。モデルをソリッドで作るのは、上面もスライサーの自動インフィルで支えて安定して印刷するためです。
- 軽量タイプは1種類のみです。以前の片側開放モデルとは別ファイルです。

## Flashforge Adventurer 5M / PETG 設定
1. `KUBB_70x70x150_CLOSED_LIGHT_PRINT.stl` をOrca-Flashforge / FlashPrintに読み込みます。単位mm、倍率100%。
2. **Z方向150mmで立てて印刷**。STLはビルドプレート中央へ置いた向きに設定されています。
3. ノズル0.4mm、レイヤー高さ0.2mm。
4. **壁の数（Wall loops）：2周**。壁の隙間を減らして少し丈夫にしたい場合は3周。
5. **インフィル密度：5%**、パターン：Gyroid（ジャイロイド）あるいはGrid。特に軽くしたい場合3%も可（上面の品質は下がりやすくなります）。
6. **上面：4層、底面：4層**（0.8mm）。上面が垂れる場合は上面を5〜6層、インフィルを8%程度へ増やします。
7. **サポート：OFF**。面取りは1.5mm程度なので通常サポート不要。内部は5%インフィルが上面の足場になります。
8. ノズル235〜245℃、ベッド75〜85℃を目安に、PETGメーカー指定を優先。
9. 初層は低速（15〜25mm/s目安）、必要ならブリム4〜5mm。冷えてからプレートから外します。
10. **必ずスライスプレビューで中身が5%程度の格子、上面4層で塞がれている**ことを確認してから印刷してください。完成重量はスライス後のフィラメント使用量表示が最も確実です。

## 注意
内部を完全に空にして上面を150mm高で橋渡しさせるのは印刷に不向きです。このデータはスライサーのスパースインフィルを利用する方式なので、内部は少量の支柱が残ります。
室内でもPETGは硬く、床・家具に傷や音が出る可能性があります。滑りにくく柔らかいマットの上で使用してください。実機での耐衝撃性は未検証です。
