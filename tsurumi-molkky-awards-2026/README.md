## 材料・印刷に関する注意

- 材料：半透明赤PETGを想定。文字はプリント後にシルバーのペンで着色する予定。
- 使用機：Flashforge Adventurer 5M。
- 文字・葉・王冠などの装飾や張り出し部分に注意し、**FlashPrintでスライスプレビューとサポート量を確認**してから印刷してください。
- STLはデジタル上の造形確認をしたデータです。**実機印刷とサポート除去については未検証**です。
