# Flashforge Adventurer 5M — TPU 95A安定印刷メモ

## 症状
以前の印刷では「最初は吐出するが、途中から樹脂が出なくなる」ことが複数回発生。0.4mmノズルで頻発したため0.8mmへ移行する方針。**ノズル径変更だけで送り不良が解消するとは限りません。**

## 詰まりを減らすためのチェックリスト
1. **印刷物の前にロードで連続吐出できるか確認**。途中停止時は印刷を中断。詰まり状態で無理に押し込まない。
2. TPUのリールが軽く回ること、送り経路と白いガイドチューブが強く曲がらないことを確認。
3. 使用フィラメントの**推奨温度**を使う。メーカー指定の乾燥条件があればその範囲内で乾燥。
4. 最初は外壁・内部とも**15〜20mm/s程度**の低速、最大体積速度**1.5mm³/s**など低めに設定して検証。
5. **リトラクション0mm**で一時的に比較し、引き戻し起因の送り不良か切り分ける。糸引きが増えるため、原因が分かったら適量へ戻す。
6. ノズル内の古いPETG、送りギアに絡んだTPUや削れ粉を確認。清掃やノズル交換はFlashforgeの公式手順に従う。
7. 0.8mmノズルに替えたら、**プリンターとスライサー両方で径を更新して再スライス**。0.4mm向けの微細な穴・文字・ヒンジは作り直す可能性がある。
8. 2節などの**短いテストを最後まで完走**させるまで本番の長時間ジョブを開始しない。

## ビルドプレート
標準のPEI鋼板でもTPUを印刷できます。TPUは強く貼り付く場合があるため、冷却後に慎重に取り外し、表面仕様に応じて剥離補助材の使用を検討。プレート交換は**途中で吐出が止まる症状の直接の解決策ではありません**。
